# Landing Posté ! (poste.ultrafacile.fr)

Page du produit **Posté !** (ULTRAFACILE) : génération de publications réseaux sociaux à partir des vraies photos du client, validation 1 clic, publication automatique. Pas d'image IA.

Site statique, `index.html` autonome. Rebrand de l'ancienne LP EasySN (nom commercial = Posté !). CTA de réservation : TidyCal `tidycal.com/ultrafacile/15-min-pour-voir-si-poste-est-fait-pour-toi`.

## Contenu
- `index.html` : la page.
- `assets/hero-lockarting.jpg` : visuel hero (à remplacer par une vraie photo client quand dispo).
- `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` : favicon UF.

## Déploiement
Statique. Uploader le contenu à la racine web du sous-domaine `poste.ultrafacile.fr` (Hostinger), ou déployer via l'intégration Git Hostinger depuis ce dépôt.

## Coût d'exploitation
Aucun coût d'hébergement propre (statique). Dépendances gratuites : Google Fonts. Réservation via TidyCal (offre de Sabine).
